• Demo flow (5–7 bullets):
Alena: Start Screen: discuss the concept and rules of the game, show off the settings, and continue.
Alena: Character Selection: Show all the options users can choose from and how you can choose between different colors, faces, and shapes.
Gavin: Levels 1-3: At level 1 show off coins, enemies, progression, and win condition. At level 2 show how each level map is different. At level 3 explain dashes, hearts, and new moving enemy type.
Gavin & Alena: Gavin explains pause mechanism and Alena explains settings options.
Gavin: Levels >3: Tiles disappear more quickly, level layouts become more complex.
Alena & Gavin: Game over screen explanation and shows off time & score save mechanism.
Gavin: Showing off how the game resets after game over.

• Best moments:
Character customization: The user has the option to select fun, unique characters to play as.
Level 3: User is introduced to new items and enemy types.
Level 6: The user is prompted with a hard start and has to adapt.
